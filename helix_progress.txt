----------------------------------------------------
0. GLOBAL BOT STRUCTURE
----------------------------------------------------
The bot is structured into multiple cogs:

• core.py        — main utility commands (help, prefix, stats, broadcast, etc.)
• mod.py         — full moderation system
• fun.py         — entertainment commands (gif, trivia, polls, etc.)
• userinfo.py    — user profile commands
• utility.py     — server utilities (role management, info commands)
• secret.py      — clone system (owner-only)
• access.py      — allowrole-based access control system
• tools.py       — mkgif image/video → GIF converter
• help_descriptions.json — central help reference file

The bot uses:
- Prefix commands via discord.ext.commands
- Custom dynamic help command
- JSON persistence for warning logs, modlogs, allowroles
- Global checks for permission control
- MoviePy for GIF conversions
- Buttons, dropdowns, and reactions for interactions
